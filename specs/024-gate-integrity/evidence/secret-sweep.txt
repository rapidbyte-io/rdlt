  Method note: the passphrase is four characters, so a raw substring search over
  the tree returns hundreds of coincidences and no leaks. It is matched only
  adjacent to an assignment and a credential word — the shape a real leak has.
  Key material is checked by SHAPE, not value: a credential file committed from
  another machine passes every value check and fails the file-name and
  base64-body checks.
