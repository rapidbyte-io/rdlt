# Contract: File Family Rules (FF1–FF8)

| # | Rule |
|---|---|
| FF1 | One family, frozen behavior: the unified crate holds source and destination with shared `location/` and `formats/` layers; the standalone parquet crate's behavior, staging/receipt/cursor persisted formats (versioned), fail-point names, and pipeline-YAML spellings (`file:` source, `parquet:` destination) survive BYTE-COMPATIBLE. Pre-015 documents (config and persisted state) parse and resume unchanged. |
| FF2 | Complete-or-fail discovery: file listing is deterministic (lexicographic), COMPLETE across listing pagination, and honest — empty match-set is success, an explicitly named missing file, unreachable endpoint, or unauthorized bucket is a typed error naming the subject. A partial listing must never pass as a complete one. |
| FF3 | One cursor rulebook: per-file progress (done/size/boundary/identity) governs both location kinds — completed skipped, grown tails resumed where the format permits, shrunk or rewritten-in-place (mtime/etag tripwire) loudly fatal naming the file, compressed files whole-file units. Exactly-once outcomes across re-listing ride the engine checkpoint machinery. |
| FF4 | Formats are shared and typed: jsonl (fast path preserved), csv (record stream via documented inference lattice + `type_hints` override; malformed row typed with file+row), parquet (structured, S7, row-group units). Codec by extension (gzip/zstd, jsonl/csv only); codec/extension mismatch typed. One module defines each format for BOTH directions. |
| FF5 | Commit-atomic visibility: staged writes live under staging-designated names only; finalize at commit is the visibility event; a reader can NEVER observe a partial object under a final name, on either location kind. Recovery converges — deterministic final names per (load, commit, table, n), idempotent re-finalize, superseded staged leftovers. Receipts remain the set-commit witness. |
| FF6 | Secrets and classification: object-store credentials are `Secret`-wrapped (never render, grep-proof cell); errors classify per the S3 posture — store network/5xx/throttle transient (engine budget), malformed data/config/identity-tripwires fatal, all naming file/key/bucket/endpoint. |
| FF7 | Crash discipline: the preserved `pq.*` points plus `file.list`/`file.read`/`file.stage.put`/`file.finalize.copy`/`file.finalize.delete` sweep with armed-fire pins on the local matrix always and the object matrix in container cells; crash/rerun converges to exact totals. |
| FF8 | Verification: traceability matrix zero uncited rows; dlt-parity record vs dlt's filesystem source/destination with deliberate deviations named; ≥80% coverage baseline-first; live cells against the RUSTFS container (podman pattern, skip-not-fail) covering discovery, pagination-complete listing, delta-by-read-accounting, CSV options, codecs, and dest atomicity; existing gated bars (`parquet-passthrough`, `jsonl-duckdb-200k`) in-band same-session as the weld; new object-store bench cells are scoreboard (the floor would measure the test server, not rdlt). |
