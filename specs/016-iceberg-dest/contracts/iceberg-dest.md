# Contract: Iceberg Destination Rules (ID1–ID8)

| # | Rule |
|---|---|
| ID1 | One protocol, one boundary: the destination speaks ONLY the Iceberg REST catalog protocol through the surveyed library; iceberg-rust types never cross the crate's public surface — config in, typed errors and SPI receipts out (the duckdb-rs wrapping precedent). Provider-agnosticism is a consequence, not a feature flag. |
| ID2 | One engine commit = one atomic Iceberg snapshot carrying the commit identity (`rdlt.pipeline`/`rdlt.load-id`/`rdlt.commit-seq`) in its summary; a replayed identity publishes NOTHING and returns the prior receipt — exactly-once readable from table history alone, no side store. StateDoc rides table properties in the same atomic commit. |
| ID3 | Optimistic concurrency is BOUNDED: commit conflicts retry (refresh → rebuild → commit) a declared number of times, then fail typed naming the table and the competing snapshot. The destination never loops unboundedly and never drops a foreign writer's snapshot. |
| ID4 | The type mapping is CLOSED and documented; unmappable columns are typed at ensure-table naming the column; field IDs are assigned by the catalog/library, never invented; additive drift maps to Iceberg schema evolution, contradictory drift stays typed. |
| ID5 | Capabilities never silently degrade: merge is rejected by capability; if the T001 probe narrows v1 write modes (overwrite unsupported upstream), Replace is a TYPED unsupported error and the narrowing is recorded in spec/parity/README — no half-measure emulation whose failure mode is corrupted history. |
| ID6 | Secrets and classification: all credentials (client secrets, tokens, storage keys) are Secret-wrapped with the grep-proof cell; vended credentials are the default storage path (session tokens, expiry = transient); errors classify per the standing posture and always name catalog/warehouse/namespace/table/column. |
| ID7 | Crash discipline: `ice.files.write`/`ice.commit`/`ice.receipt.visible` swept ×3 actions against the LIVE local catalog (container-gated, skip-not-fail), converging to exactly-once totals AND a duplicate-free snapshot history (each identity at most once across all snapshots). |
| ID8 | Interop is the oracle: pyiceberg reads every table shape the cells write (plain, partitioned, post-drift) through the same catalog in the standard gate; Spark repeats it in the deep tier. Verification per house standard: matrix zero uncited, parity vs dlt's Iceberg support with deferrals named (Glue/SigV4 phase-2), ≥80% coverage baseline-first, scoreboard-only bench. |
